# Aegis Console

`Aegis` 的独立前端控制台，采用 `Next.js 15 + React 19 + TypeScript`。

## 启动

```bash
npm install
npm run dev
```

## 环境变量

复制 `.env.example` 为 `.env.local` 后按实际后端地址调整：

- `NEXT_PUBLIC_AEGIS_API_BASE_URL`
- `NEXT_PUBLIC_AEGIS_WS_URL`
- `NEXT_PUBLIC_AEGIS_ENVIRONMENT`
- `NEXT_PUBLIC_AEGIS_CONSOLE_NAME`
